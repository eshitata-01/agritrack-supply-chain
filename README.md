# AgriTrack
Agricultural Supply Chain Loss Detection

An Advanced SQL project to analyze agricultural losses across harvesting, storage, transportation and delivery.

## Technology Stack
- Frontend: Next.js, React, TypeScript
- Backend: Next.js API Routes
- Database: Oracle SQL

## Project Modules
- Dashboard
- Supply Chain Records
- Crop Analytics
- Storage Monitoring
- Transportation
- Shipment Tracking
- Loss Detection
- Reports
- SQL Insights
